# Research-v1 real corpus — Prompt-2

Final freeze: 210,012,790 unique usable TRAIN tokens / 128,584 documents; 8,393,991 validation tokens / 4,959 documents. Exact and normalized content duplicates and cross-split groups are zero in the audited reservoir. Actual TRAIN mix: code 62.855%, technical 17.146%, general 14.285%, structured context 5.715%. Python is 7.87% of code tokens; HTML/CSS 21.235%, Java 15.689%, C 10.785%, JavaScript 10.694%, C++ 9.270%; the machine-readable statistics retain every language. Final data footprint 9,977,340,702 bytes (9.29 GiB), including rejected attempt files. Packing and readiness passed; the target statements below describe the predeclared construction method.

[CodeParrot's pinned provider card](https://huggingface.co/datasets/codeparrot/github-code/blob/b5661e6b17396364b2bcf8e68977b0d28e1ebd19/README.md) describes repository-license annotations. Raw Parquet actually contains content/repo_name/path/size/license, with language inferred by file extension in our reader. Each admitted record retains dataset/revision/file/row/repository/path/language/license/category/content and normalized hashes. Repository commit hashes are not supplied and are not invented. License whitelist: MIT, Apache2, BSD2/BSD3, ISC, CC0 and Unlicense. Unknown/other licenses are rejected. Vendored/generated paths, generated headers and conflicting GNU license headers are additionally rejected; annotations do not constitute an independent legal audit of every file.

[FineWeb-Edu's pinned provider card](https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu/blob/87f09149ef4734204d70ed1d046ddc9ca3f2b8f9/README.md) declares ODC-By collection licensing/CommonCrawl terms. URL, original ID, crawl/file/date and education/language scores remain per document. Collection licensing is distinct from individual page ownership; missing independent page-license annotations are explicit. Require education score>=3 and language confidence>=.8, with bounded size/line/encoding quality filters.

Technical text is permissively annotated repository Markdown containing programming/documentation terms. Structured context is a deterministic10% hash-assigned code-file subset with real `<repo>`/`<file>` headers, not fabricated tool trajectories. Each source body appears in only one category. Code languages are inferred from paths; .h is classified C and HTML/CSS combined, so these are extension-based estimates. Preserve long-tail languages and cap Python at20% of final code tokens to prevent accidental dominance. Final actual token percentages are authoritative, not aspirational quotas.

Deduplication uses a global SQLite unique index for exact source-content SHA256 and conservative CRLF/trailing-newline normalized hashes. Original text is retained. Split assignment hashes seed42 plus casefolded repository for code/technical/context, or hostname for educational text; all files from a repository stay together. Web grouping is hostname, not a public-suffix registrable-domain guarantee. Final packing independently checks exact/normalized uniqueness and group disjointness over the entire reservoir before selection. Some repeated boilerplate/near duplicates beyond this normalization may remain; no MinHash claim.

Single-writer admission examined1,952,508 raw rows and admitted265,578 reservoir documents. This is candidate count, not the final LM document count after token quotas. Reservoir budgets:900MB code,240MB technical,300MB general,130MB context (plus small validation reservoirs). Local raw/candidate/failed-attempt/shard footprint is recorded and bounded below16GiB by the downloader; no multi-terabyte corpus is fetched.

The initial raw-schema assumption rejected every row; that failure report is preserved and the schema was corrected before admission. Two pre-freeze admission processes were accidentally overlapped, so that reservoir was preserved as an explicitly rejected attempt and rebuilt once under an exclusive writer lock. No quality training existed during either repair. Final source/rejection/doc/license/language/token counts and split audit are in corpus_statistics.json; only the final frozen corpus is eligible for training.

Packing emits BOS/body/EOS/doc, deterministic whole-document shuffle seed42, then uint16 physical shards. Causal attention may cross document boundaries within a split, as in the prior engine. Every model consumes the same context1024 fixed-offset permutation via existing PackedStream. Validation document indexes retain exact content IDs/hashes/offsets for category/language diagnostics. Known benchmark repository/path substrings are filtered; local micro evaluations are original fixed tasks with distinct identifiers and are never admitted into corpus construction. This is practical exclusion, not a universal benchmark-contamination audit.

Manifest source/config/split/packing/tokenizer/shard hashes are frozen before quality training. Large datasets and checkpoints are archive references by canonical path/size/SHA256/source/revision/experiment/time; final ZIP contains metadata and source, not unnecessary payload duplicates.
